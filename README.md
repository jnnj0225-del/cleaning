# cleaning

Windows PC上の不要な一時ファイル/キャッシュと、ダウンロードフォルダ内の古いファイルを掃除するためのPowerShellスクリプトです。

## スクリプト

`scripts/Clean-PC.ps1`

### 削除対象

- ユーザー一時フォルダ（`%TEMP%`）
- （オプション）Windowsシステム一時フォルダ（`C:\Windows\Temp`）
- （オプション）Edge / Chrome / Firefox のブラウザキャッシュ
- ダウンロードフォルダ内の、最終更新日から指定日数（既定30日）以上経過したファイル

### 安全設計

- **既定はドライラン**です。`-Execute` を付けない限り、実際には何も削除せず、削除対象の一覧と合計サイズだけを表示します。
- `-Execute` を付けて実行しても、削除前に `y/N` の最終確認を求めます。確認をスキップしたい場合のみ `-Force` を追加してください。
- 削除結果はデスクトップ上にログファイル（`Clean-PC_yyyyMMdd_HHmmss.log`）として保存されます。

### 使い方

PowerShellを開き、スクリプトのあるフォルダで以下を実行します。

```powershell
# 1. まずはドライランで、何が削除されるか確認する（何も削除されません）
.\Clean-PC.ps1

# 2. ブラウザキャッシュも含めて確認したい場合
.\Clean-PC.ps1 -IncludeBrowserCache

# 3. 内容を確認した上で、実際に削除する（確認プロンプトあり）
.\Clean-PC.ps1 -IncludeBrowserCache -Execute

# 4. ダウンロードフォルダの対象期間を60日以上に変更する場合
.\Clean-PC.ps1 -DownloadsDays 60 -Execute
```

スクリプトの実行がブロックされる場合は、PowerShellの実行ポリシーを一時的に許可してください（管理者権限は不要です）。

```powershell
powershell -ExecutionPolicy Bypass -File .\Clean-PC.ps1
```

### 注意事項

- ブラウザキャッシュを削除する場合は、対象のブラウザを閉じた状態で実行することを推奨します（開いたままだとファイルが使用中でスキップされることがあります）。
- ダウンロードフォルダのファイルは削除すると元に戻せません。実行前に必ずドライラン結果を確認してください。
